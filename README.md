# Libro digital: Barreras personales y contextuales para el desarrollo de la creatividad

## Publicar en GitHub Pages
1. Sube `index.html` directamente a la raíz del repositorio.
2. Abre **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
4. Guarda y espera a que GitHub publique el sitio.

Este proyecto no usa imágenes externas, carpetas adicionales, fuentes remotas ni bibliotecas externas. Todo está incluido en `index.html`, por lo que no aparecerán imágenes rotas.
