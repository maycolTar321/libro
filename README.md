# Libro digital: Barreras personales y contextuales para el desarrollo de la creatividad

Versión HTML con diseño editorial inspirado en un libro impreso: portada verde, detalles dorados, páginas color papel, tipografía serif, navegación entre las 17 páginas y ayudas desplegables.

## Publicar en GitHub Pages
1. Sube `index.html` a la raíz del repositorio.
2. Abre **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
4. Guarda y espera a que GitHub publique el sitio.

El CSS y JavaScript están integrados en `index.html`; no requiere dependencias externas.
