# Libro digital: Barreras para el desarrollo de la creatividad

Sitio estático adaptable para GitHub Pages. Incluye las 17 páginas del documento original como imágenes para preservar su formato, tablas y gráficos, además de una sección de ayuda con la traducción al español de las partes en inglés.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html`, la carpeta `paginas/` y este `README.md`.
3. En el repositorio, entra a **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**, selecciona `main` y `/ (root)`, y guarda.
5. GitHub mostrará el enlace público del libro cuando termine la publicación.

No requiere instalación, servidor ni dependencias.


### Mejoras de lectura
- Estilos CSS modernos con tarjetas, sombras suaves y animaciones discretas.
- Diseño adaptable a móviles, tabletas y computadoras.
- Tarjetas desplegables con explicaciones de conceptos académicos.
- Se respetan las páginas originales; las traducciones y ayudas se presentan como apoyo aparte.
- Se desactivan las animaciones automáticamente si el dispositivo tiene activada la preferencia de movimiento reducido.
